# العينة والتدريب - إصدار 2.4

التشغيل الفعلي يبدأ دون أي بيانات عينة. أنشئ قاعدة PostgreSQL مستقلة يبدأ اسمها bin_doul_sample، ووجّه اتصال نسخة تدريب من المشروع إليها، ونفذ الترحيلات وأنشئ مدير العينة، ثم من backend:

```powershell
.\.venv\Scripts\python.exe -m shift_app.cli seed-sample
```

يرفض المولد أسماء قواعد التشغيل ويرفض وجود ورديات. يضيف موظفين بكلمات عشوائية غير مطبوعة، وورديات في الشهر الحالي والسابق مع مشتريات وPDF وأصناف خارج الجهاز وتحويلات واعتمادات إدارية وحالات معلقة. لا ينشئ جردًا أو عجزًا وهميًا، ولا مهام إرسال بريد أو واتساب حتى لو تركت إعدادات القنوات بالخطأ. يمكن لمدير العينة تحديد كلمات موظفي التدريب من صفحة المستخدمين.

ملفات PDF ذات اسم v2 وacceptance-example.json الموجودة هنا **أمثلة تاريخية محفوظة من الإصدارات السابقة** وليست مخرجات النموذج الحالي. حذفها ضمن قائمة المراجعة يحتاج موافقة المستخدم. لا تستوردها إلى قاعدة التشغيل. أعد DATABASE_URL إلى قاعدة التشغيل بعد التدريب، أو استخدم نسخة مشروع تدريب مستقلة لتجنب الخطأ.
